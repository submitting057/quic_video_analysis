# 2026-11-17：Snapchat 迁移 pilot 解密审计

## 本次内容

在 YouTube（QUIC）加密视频识别取得初步成功后，用 10 个本地采集的 Snapchat
Spotlight pilot 会话（含 sslkey）回答"YouTube 经验能否迁移到 Snapchat"。
对全部会话做了 tshark 离线解密（请求 URL、响应头、HTTP/3 流重组、响应体
grep），并把结论整理为可执行的采集修复清单。

## 核心结论

1. **10 个会话里 9 个没有下载任何视频字节**（解密后零媒体 GET）——采集协议
   的缓存清理与起播验证失效，是一切信号检验的前置瓶颈；
2. **解密侧归因工具链全部打通**：视频/封面/推荐位对象在 URL 与流级完全可分，
   `/context/spotlight` 响应逐字回显视频 token（目标与推荐位可精确区分）；
3. **缓存未清实锤**：媒体请求从整 KiB 断点续传、文件头部从未上网；
4. 辅助通道拿到首个"字节随视频变化"的正面证据（context 响应含音乐元数据），
   独立性量化待修复采集后重测。
