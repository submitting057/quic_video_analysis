# 开放集识别、实验矩阵与反捷径评估

现实中的 YouTube 视频数量巨大，系统不能假设所有查询都属于指纹库中的已知视频。因此除闭集分类外，还必须设计开放集识别和 `unknown` 拒识。

## 闭集分类

所有查询视频都属于已知集合：

```text
Session Encoder → Softmax → video_id
```

适合作为概念验证，但不能代表现实部署。

## 开放集检索

更推荐使用 embedding Gallery：

```text
Session Encoder
→ embedding
→ 与视频 Gallery 中的多个原型比较
→ 最近邻候选
→ 拒识阈值
→ video_id 或 unknown
```

同一个视频应保存多个原型，以覆盖日期、设备、网络、清晰度和 Codec 变化。

训练目标可使用：

```text
分类损失 + supervised contrastive loss
```

正样本对：同一 `video_id`、不同播放条件的会话。负样本对：不同 `video_id` 的会话。

## 推荐输入对照

1. 极简统计：观察窗内总上下行字节、包数和持续时间。
2. 仅有符号 UDP payload 长度序列。
3. 包长 + 全局 IAT。
4. 包长 + 全局/路径 IAT + 相对时间 + 匿名路径。
5. 20/100/500 ms 多尺度时间 Bin。
6. Burst 序列。
7. 事件序列与多尺度 Bin 双视图融合。

主模型必须明显优于只使用“总流量/平均吞吐量”的简单基线，否则模型可能没有学到细粒度视频结构。

## 观察时长

```text
10 秒：早期识别能力
30 秒：推荐主实验
60 秒：信息更充分时的上限
```

不同观察时长应独立报告。固定前 N 个包会使高速连接覆盖更短时间，因此视频识别更适合先固定墙上时间，再对变长事件数做 Padding 和 Mask。

## 数据划分

- 同一次播放的所有连接、窗口、Burst 和增强样本必须位于同一 split。
- Gallery 只能由训练数据生成，测试会话只能作为 Query。
- 闭集测试包含相同 video ID 的独立播放会话。
- 开集测试包含从未进入训练和 Gallery 的完整视频 ID。
- 训练、校准和测试的 unknown 视频 ID 也应彼此隔离。
- 不能先切成大量窗口后随机拆分。

## 反捷径实验

### 环境交叉测试

训练于网络、设备和日期 A，测试同一批视频在新的网络、设备、日期、CDN、浏览器和 Codec 下的表现。

性能大幅下降说明模型可能学到了环境，而不是视频。

### 配对网络实验

```text
多个视频经历同一组网络 Trace
同一视频经历多组网络 Trace
```

预测应主要随视频变化，而不是随带宽、RTT 或丢包轨迹变化。

### 输入消融

依次比较：

```text
signed length
+ global IAT
+ path IAT
+ relative time
+ anonymous path
```

并比较事件序列、时间 Bin、Burst 和双视图模型。

### 时间结构检验

- 在短窗口内打乱事件顺序，同时保持总字节数不变。
- 将不同会话的包长序列和 Timing 序列交换。
- 只保留总字节和包数运行简单分类器。

如果性能几乎不变，说明模型主要利用粗略流量体积，而没有学习视频特有的时序结构。

### 身份字段检查

- 确认输入中不存在 IP、端口、CID、CDN、文件名和绝对时间。
- 随机置换匿名路径编号，检查模型是否依赖固定连接顺序。
- 使用 embedding 训练线性探针预测设备、日期、CDN 和网络 Profile。

探针准确率过高意味着 embedding 中保留了较强的环境身份信息。

### 起点鲁棒性

测试：

```text
-10、-5、0、+5、+10、+20 秒
```

报告准确率和拒识指标随起点偏移的曲线，并加入页面加载、广告和背景 QUIC 连接。

### 网络扰动

使用真实实验或可复现网络 Trace 改变：

```text
带宽、RTT、抖动、丢包、重排、MTU、ABR、清晰度
```

不要只对数值张量添加任意噪声，因为这不一定对应真实网络机制。

### 播放行为

对同一视频覆盖：

- 从开头播放和随机 Seek。
- 冷缓存和热缓存。
- 广告和无广告。
- 不同音视频表示与清晰度切换。

避免模型只记住固定开场行为。

## 推荐指标

| 指标 | 回答的问题 | 趋势 |
| --- | --- | --- |
| Closed-set Macro F1 | 已知视频之间能否平衡分类 | 越高越好 |
| Open-set Macro F1 | 将 unknown 作为额外类别后的整体表现 | 越高越好 |
| Known-vs-Unknown AUROC | 已知与未知分数是否可排序分离 | 越高越好 |
| AUPR-Unknown | unknown 为正类时的精确率和召回率 | 越高越好 |
| FPR@95%TPR-Unknown | 找回 95% unknown 时误拒多少 known | 越低越好 |
| OSCR | 正确分类已知与拒绝未知的联合能力 | 越高越好 |
| Unknown Recall | 最终阈值拒绝了多少真实 unknown | 需结合 known 误拒分析 |

还应报告低基准率场景下的 Precision，因为真实世界中某个特定视频出现概率可能很低。

## 推荐实验顺序

```text
1. 极简统计和规则指纹基线
2. 最小包事件序列
3. 完整事件序列 + 匿名路径
4. 多尺度时间 Bin
5. 开放集 embedding Gallery
6. 双视图融合
7. 跨日期、网络、设备和 Codec 的隔离验证
```

研究成功不能只由同分布准确率证明。核心问题是：模型能否在跨网络、跨日期、跨设备、跨清晰度和跨 Codec 条件下，仍然利用视频特有的多尺度下载结构，而不是记住 CDN、网络环境或采集批次。
