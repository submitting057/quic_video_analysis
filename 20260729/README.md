# 2026-07-29：PCAP、QUIC 与 YouTube 视频 ID 识别概述

整体研究链路为：

```text
原始 PCAP
→ UDP Datagram 事件
→ 播放会话
→ 规则指纹或深度表示
→ video_id / unknown
```

## 核心结论

- PCAP 保存的是捕获记录，五元组、QUIC 字段和应用层语义都需要从原始包进一步解析或推断。
- 无密钥旁路分析中，推荐将一个 UDP Datagram 作为稳定的基本事件，而不是假设一个捕获记录等于一个 QUIC Packet 或媒体分段。
- 同一 QUIC 连接可能跨多个路径和五元组；同一播放会话也可能涉及多个 QUIC 连接。
- 规则方法适合使用观测 Burst 序列建立显式指纹库；端到端方法适合从包长、方向、时间和多尺度流量结构学习 embedding。
- 现实部署必须支持 `unknown`，并通过跨日期、网络、设备、浏览器、Codec 和 CDN 的隔离测试排除环境捷径。

> 合规说明：视频流量指纹可能暴露用户的观看兴趣和其他敏感偏好。研究和实验应仅使用自采、获得明确授权或合法公开的数据，并在公开前移除 IP、端口、账号、时间和文件路径等可关联信息。
