# 2026-08-17：加密视频 ID 识别代表性方法精讲

## 概述

本目录整理 2018—2026 年加密视频 ID 识别的代表性文献，面向约 19 分钟的研究生汇报。内容从网络侧威胁模型出发，精选 4 篇传统特征与显式指纹方法、6 篇深度学习方法，按“片段指纹—序列 CNN—结构化表征与开放世界检索”的演进路线组织。

主题文档采用 12 页 PPT 制作稿形式，严格区分可直接放入页面的关键文字、口头讲解备注和正式来源。不同论文的数据集、类别规模与观察时间不同，因此横向比较聚焦能力边界，不按 accuracy 排名。

## 核心结论

- 加密载荷不会消除 packet length、direction、IAT、Burst、segment、request 和 QUIC Stream 行为形成的内容侧信道。
- 显式指纹仍具有可解释、易更新和适合大规模候选检索的优势，并未被深度学习完全替代。
- 深层序列模型的关键贡献是从原始方向、时间与流量节奏中自动学习表征，但实验结论必须结合闭集、固定播放位置和数据划分理解。
- 面向真实 YouTube QUIC/HTTP/3，更可行的技术组合是：结构恢复、候选检索、学习重排、unknown/OOD 拒识和跨日期增量更新。
- Deep Fingerprinting 属于 Website Fingerprinting 方法迁移论文，不是视频 ID 核心论文。
